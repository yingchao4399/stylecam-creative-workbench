# StyleCam 创作工作台｜第六课基础版

Windows 桌面应用，复刻第六课的素材进入、旋钮选风格、强度确认、生成、查看、对比、保存与收起。顶部图标由“取景框＋旋钮”组成。当前先交付并验证**基础版**；跨场景复用等进阶版尚未申报完成。

第六课的完整实践过程、真实千问出图、测试结果和待现场补齐的实体硬件证据见[作业实践报告](docs/第六课作业-StyleCam实践报告.md)。

## 启动

安装 Node.js 20 或更新版本，在本目录执行：

```powershell
npm ci
npm start
```

生成 Windows 免安装目录：

```powershell
npm run package:win
```

程序位于 `release/win-unpacked/StyleCam 创作工作台.exe`。`.ico` 图标已写入可执行文件；图标源文件和重建脚本分别是 `assets/icon/stylecam-mark.svg`、`npm run icon:build`。

## 先做一轮

应用启动后自动装载原创机器人示例。用方向键或把鼠标放到中间画面上转动滚轮，浏览毛线手作、软陶微景、像素午后三种风格；浏览**不会**提交生成。按 S1 或数字 `1` 进入强度调节，转动旋钮改变档位，按 `Enter` 确认；再按 `Enter` 或点击“生成作品”。演示模式会把预生成的同主体样片放进作品桌面，并标明“样片演示”。

可拖入或选择自己的 PNG、JPG、WebP 图片，限制 15 MB、长宽 128～8192 像素。没有图像服务密钥时，对自定义图片生成的是**本地显示效果**，界面会明确标注“非 AI”。两种演示都能完成查看、对比、保存、收起及历史作品流程。

作品自动存入 Electron 用户数据目录的 `works` 文件夹。S3 或预览窗“保存到文件”会打开系统另存为对话框；S4 只收起预览，作品仍留在底部作品桌面。

## 键位

| 输入 | 动作 |
| --- | --- |
| 画面区滚轮、方向键 | 浏览风格；强度模式中调整档位 |
| `Enter` / `Space` | 确认强度，或明确发起生成 |
| 数字 1～8 / F1～F8 | S1～S8 对应动作 |
| `Ctrl+Alt+Shift+1…8` | 兼容第五课复读机的八键配置 |

S1 强度、S2 查看、S3 保存、S4 收起、S5 对比、S6 灵感、S7 重置、S8 本地显示模式。输入框获得焦点时创作快捷键暂停，画面区以外的滚轮仍正常滚动。**实体板键值尚需按现场配置实测**；在本机可以先用普通键盘模拟。

设备诊断窗口还提供“实体键校准”：选择 S1～S8 或旋钮短按，点击开始校准，再按一次对应实体键，实际浏览器键值会保存在本机并优先用于 StyleCam。旋钮左右若作为滚轮上报，直接在中间画面区域操作即可；厂商 HID 不产生浏览器事件时，仍需使用 `scripts/capture-easyinput-keys.ps1` 记录原始报告。

## 可选的实时 AI 图像编辑

也可以直接点击窗口右上角的“设置”，选择 OpenAI、阿里云百炼/千问、火山引擎/豆包、Moonshot/Kimi、Google Gemini 或其他 OpenAI 兼容服务。填写服务地址和 API Key 后，点击“获取官方模型”读取模型列表，再点击“测试连接”和“保存设置”；密钥由 Electron 主进程写入本机用户数据目录，页面只显示掩码，不会把完整密钥放进作品记录或截图。留空 API Key 会沿用已保存密钥。千问默认使用北京地域官方 Base URL；若 Key 属于其他地域，可在设置中填写该地域的官方地址。基础版验收时可以不填密钥，使用已标注的样片演示。

Codex CLI 选项只用于开发测试配置页和连接流程，不能把 Codex 桌面登录直接当作图片生成 API。Kimi 等文本模型可以连接和测试，但当前 StyleCam 图片编辑适配器优先支持 OpenAI Images 和兼容 `/images/edits` 的服务；其他服务先完成连接配置，适配器按服务商接口逐步补齐。

应用仅在主进程读取密钥，不把密钥写入页面源码、作品记录或截图。在 PowerShell 当前会话设置后启动：

```powershell
$env:STYLECAM_API_KEY = '在你自己电脑上填入密钥'
$env:STYLECAM_IMAGE_MODEL = 'gpt-image-2'
npm start
```

默认请求 `https://api.openai.com/v1/images/edits`；千问图生图使用 DashScope 原生图像编辑 API，具体协议见[千问接口接入说明](docs/千问官方图像接口接入说明.md)。其他 OpenAI 兼容服务可设置 `STYLECAM_API_BASE` 和 `STYLECAM_IMAGE_MODEL`。服务协议、模型可用性和费用由用户所配置的服务决定。点击“实时 AI”并主动生成时才会把当前原图发送给服务。没有密钥时按钮会提示原因，不会伪装成实时生成；网络结果未知时也不会自动重试。

## 证据与当前状态

- `npm test`：验证风格切换不触发生成、强度确认、重复生成保护、作品保留、键位归一化及本地作品库。
- `STYLECAM_SMOKE=1` 启动：自动跑通原创示例样片、导入自定义图片、本地效果、原图对比和收起后保留作品。截图见 [基础版工作台](docs/basic-workbench-smoke.png)。
- [作业实践报告](docs/第六课作业-StyleCam实践报告.md)记录了已证实与待现场实测的项目。
- [基础版验收矩阵](docs/基础版验收矩阵.md)逐项区分软件验证、设备枚举和实体板待测证据；硬件监听器会过滤 `VID_303A&PID_1006`，并记录键盘、鼠标及厂商 HID 原始报告。

内置原图与三种风格变体由 `imagegen` 生成，提示词与来源记录见 [样片说明](docs/原创风格样片说明.md)。软件演示与 Windows 打包已完成；一次千问 `qwen-image-2.1-pro` 真实图生图已成功，证据见实践报告。实体 EasyInput 操作、最新版发布包完整烟测和 60～120 秒现场录屏仍待补齐。
