# 原创风格样片说明

本组素材由 Codex 内置 `imagegen` 工具生成，作为第六课 StyleCam 的同主体个人风格实验。主体是一只青绿色桌面机器人：圆角矩形头部、两个深色椭圆眼睛、乳白色机身、胸前橙色圆钮；固定站在有笔记本的浅木桌前。原图与三个变体均已保存在 `assets/styles/`。它们是预生成的示例素材，应用中明确标注“样片演示”。

| 文件 | 内容 | 观察点 |
| --- | --- | --- |
| `source-robot.png` | 日光下的产品摄影原图 | 身份、姿势和构图基线 |
| `wool.png` | 毛线与针毡手作 | 纤维、针脚与材质变化 |
| `clay.png` | 软陶定格微景 | 手捏纹理、边缘与暖光 |
| `pixel.png` | 像素午后 | 大像素、限定色盘与主体可识别性 |

原图提示词：生成正方形产品摄影，青绿色机器人、圆角矩形头部、深色椭圆眼睛、乳白机身和橙色胸钮，站在窗边浅木桌上，旁边有无字笔记本；无文字、标志、边框。三个变体分别要求保留同一机器人身份、姿势、构图和桌面元素，只改成针毡毛线、手捏软陶、清晰像素画语言。生成方式为内置 `imagegen`；没有调用本应用的“实时 AI”接口。

课堂实验结论：同一主体固定后，风格差异更容易比较。低强度保留轮廓与布局，高强度允许改材质与背景；“强度”只是提示词约束，不代表模型输出按百分比线性变化。
