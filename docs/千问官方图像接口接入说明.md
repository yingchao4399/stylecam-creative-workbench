# StyleCam 千问官方图像接口接入

更新时间：2026-10-15

## 官方依据

- [千问图像生成与编辑 API 参考](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)
- [千问 Qwen-Image 文生图 API](https://help.aliyun.com/zh/model-studio/qwen-image-api)
- [千问 Qwen-Image-Edit API](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)

## 选型和请求协议

StyleCam 上传原图后需要做图生图（I2I）。当前图片编辑走官方 DashScope 同步调用协议；模型列表通过 OpenAI 兼容模式的 `/models` 查询。两条请求路径用途不同：

- 默认模型列表 Base URL：`https://dashscope.aliyuncs.com/compatible-mode/v1`（北京）。其他地域可填写该地域官方地址；若控制台提供业务空间专属域名，可粘贴其完整兼容模式 Base URL。模型、Key 与地址必须属于同一地域。
- 图像编辑请求地址：`POST /api/v1/services/aigc/multimodal-generation/generation`
- 身份认证：`Authorization: Bearer <百炼 API Key>`
- 请求体使用 DashScope `input.messages` 与 `parameters` 结构；消息内容包含 Base64 data URL 原图和编辑提示词，参数包括 `n`、`size`、`prompt_extend`、`watermark`
- 生成尺寸按原图宽高比计算，在千问官方尺寸范围内输出；提示词要求保留主体与完整构图
- 百炼返回带有效期的图片 URL，应用立即下载并保存到本地作品历史
- 设置页“测试连接”会查询模型目录，再向图像接口发送缺少 `model` 的空请求，以接口校验响应确认路由可达；不创建计费生成任务

## 图片模型

设置中的千问目录仅列官方支持图生图的图片模型：

| 模型 | 适用说明 |
| --- | --- |
| `qwen-image-3.0-pro` | 3.0 Pro，优先推荐 |
| `qwen-image-3.0` | 3.0 标准模型 |
| `qwen-image-2.1-pro` | 2.1 Pro |
| `qwen-image-2.1-turbo` | 2.1 Turbo |

千问文本模型（例如 `qwen-plus`）不能作为图片编辑模型。设置页通过当前 Key 的 `/models` 结果筛出官方图像型号，避免选择该 Key 未开通的模型。官方参考中列有 `qwen-image-3.0-pro`、`qwen-image-3.0`、`qwen-image-2.1-pro` 和 `qwen-image-2.1-turbo`；当前 Key 的实际可用项以接口返回为准。

## 区域与密钥

API Key 和 Base URL 必须属于同一地域。图像请求使用与 Base URL 相同主机名下的 DashScope 原生路径，不能把原生路径拼到 `/compatible-mode/v1` 子路径后面。若接口返回 404，先核对模型、Key 与地域是否一致。设置页的“测试连接”检查模型目录并探测 DashScope 原生路由，不会创建图片任务。

百炼 Model Studio 官方文档：[千问图像生成与编辑 API 参考](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)。

## 图片尺寸处理

- 百炼图像编辑接口输入图片上限为 10 MB。超过 10 MB 或单边超过 2048 像素时，StyleCam 会在本机缩小并转为 JPEG 后再发送，原始素材仍保留在本地作品记录中。
- 输入长短边超过 10:1 时提示先裁切。图片编辑框、作品查看器和本地效果保留图像比例，预览使用完整图像，不作中心裁切。
- 模型输出链接由应用立即下载，不会把 API Key 发给图片存储域名。

## 验证

`tests/image-provider.test.mjs` 覆盖官方模型目录、地域 Base URL 规范化、DashScope 图生图 JSON 请求体、临时图片 URL 下载、文本模型拦截、API 错误码及无费用连接测试。2026 年 10 月 15 日，本机已用 `qwen-image-2.1-pro` 完成一次真实百炼图生图；其他模型和素材尚未逐项实测。
