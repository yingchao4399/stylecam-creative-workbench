## 已具备

- Windows 工作台：`release/win-unpacked/StyleCam 创作工作台.exe`
- 源码和启动说明：项目根目录 `README.md`
- 原创主体与三种风格：`assets/styles/`
- 样片来源说明：`docs/原创风格样片说明.md`
- 软件验收记录：`docs/基础版验收矩阵.md`
- 课程交付说明与个人思考初稿：`docs/基础版作业交付记录.md`
- 工作台烟测截图：`docs/basic-workbench-smoke.png`
- EasyInput 诊断脚本：`scripts/capture-easyinput-keys.ps1`

## 提交前必须补齐

1. 录制 60～120 秒操作视频。若使用普通键盘，标题、口播和画面文字都写明“键盘模拟”；只有手部操作 EasyInput 时才标“实体板实测”。
2. 视频中展示：原图、旋钮/方向键浏览三种风格、S1 调强度、确认、生成、S2 查看、S5 对比、S3 保存、S4 收起后作品仍保留。
3. 若声称“实时 AI 生成”，在设置中配置自己的图像服务 API Key，并保留一次成功结果；没有 Key 时使用“样片演示”或“本地显示效果”标签。
4. 若声称“硬件联调完成”，先运行 Raw Input 监听并逐个操作 S1～S8、旋钮左右和短按。记录必须出现 `VID_303A&PID_1006` 对应路径的 `keyboard`、`mouse` 或 `hid` 事件。

## 推荐录屏顺序（约 90 秒）

| 时间 | 画面与操作 |
| --- | --- |
| 0–12 秒 | 启动工作台，展示原创原图和“样片演示”状态 |
| 12–32 秒 | 浏览毛线、软陶、像素三种风格，说明浏览不会立即生成 |
| 32–48 秒 | S1 进入强度调节，旋钮调到目标档位，短按确认 |
| 48–67 秒 | 明确发起生成，展示作品出片和状态标签 |
| 67–82 秒 | 查看、原图对比、保存到文件 |
| 82–95 秒 | 收起预览，展示作品仍在作品桌面，并口述一个交互取舍 |

## 真机监听

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\capture-easyinput-keys.ps1 -Seconds 60 | Tee-Object -FilePath .\docs\hardware-capture-latest.txt
```

先确认 Windows 能看到三个设备集合：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\capture-easyinput-keys.ps1 -ListDevices
```

没有实体按压时，`Capture finished: 0 device events.` 只表示监听器正常运行，不构成硬件联调通过证据。
