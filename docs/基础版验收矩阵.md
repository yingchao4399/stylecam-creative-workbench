## 实体板补测命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\capture-easyinput-keys.ps1 -Seconds 60
```

监听期间依次按 S1、S2、S3、S4、S5、S6、S7、S8，旋钮向左、向右、短按各两次。有效输出必须带有 `VID_303A&PID_1006` 对应设备路径：

- `keyboard VK=...`：键盘类按键；
- `mouse ... wheel=...`：标准鼠标/滚轮类旋钮；
- `hid ... data=...`：厂商 HID 原始报告。

没有实体操作时输出 `Capture finished: 0 device events.` 只证明监听器正常，不证明硬件映射完成。
